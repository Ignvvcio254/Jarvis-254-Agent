# PRPs Directory

Directorio de plantillas y artefactos PRP (Product Requirements Proposal) para el sistema SaaS Factory.

## Contenido

- `prp-base.md` — plantilla base para definir features complejas antes de implementación.

## Uso recomendado

1. Duplicar `prp-base.md` y crear `PRP-XXX-<feature>.md`.
2. Completar objetivos, alcance, modelo de datos, fases y criterios de aceptación.
3. Aprobar PRP antes de ejecutar cambios multiarchivo.
4. Ejecutar implementación por fases con `skills/bucle-agentico/SKILL.md`.

## Integración

- Sistema global: `SAAS_FACTORY.md`
- Comandos de soporte: `COMMANDS.md`
- Trazabilidad: `commands/memoria.md`
