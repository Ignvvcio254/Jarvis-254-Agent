## Notas de uso

- Mantener assets livianos y web-safe.
- Priorizar documentación en markdown para principios, referencias e implementación.
- Si agrega un nuevo sistema, incluir al menos un `*.md` y opcionalmente `images/`.

## Selección de sistema visual

- `bento-grid` — dashboards y landing pages modulares.
- `gradient-mesh` — estética moderna con profundidad de color.
- `liquid-glass` — UI translúcida con capas y blur.
- `neobrutalism` — alto contraste y personalidad fuerte.
- `neumorphism` — superficies suaves y profundidad sutil.

## Integración con implementación

- Usar este índice junto con `rules/web/design-quality.md`.
- Documentar en PR qué sistema visual se eligió y por qué.
- Mantener consistencia de tokens/espaciado entre pantallas.
