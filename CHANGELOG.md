## [0.3.0] — 2026-10-14

### Added
- Claude Code plugin `jarvis-harness` + marketplace (`/plugin install jarvis-harness --marketplace Ignvvcio254/Jarvis-254-Agent`), generated by `scripts/build_plugin.py` (CI checks it is in sync).
- One-line installers `scripts/bootstrap.sh` / `scripts/bootstrap.ps1`.
- `verify_gate.py`: cross-platform port of `verify-gate.ps1` (no PowerShell needed).
- `models/claude-multi.sh`: multi-model launcher for macOS/Linux/WSL with HMAC proxy check.
- `AGENTS.md`: portable contract for Codex, OpenCode, Cursor, Gemini CLI.
- `install.py --name` fills `{{YOUR_NAME}}` on a fresh install.
- Bilingual (EN/ES) archetype router and correction detector.
- CI: macOS, Python 3.13, clean-install E2E on 3 OSes (bootstrap → hooks run → verify gate → gateway health).

### Fixed
- Python detection skips the Windows Store `python3` stub (bootstrap and plugin hooks).
- `verdict_guard` points to the real gate/stamp paths for plugin and manual installs.
- `INSTALL.md` no longer tells users to copy templates over `~/.claude.json` / `settings.json`.

## [0.2.0] — 2026-10-14

### Added
- `install.py`: idempotent installer; merges hooks into `settings.json` with backup, never overwrites user config or profiles.
- Harness core skills: `verify-repair` (+ `verify-gate.ps1`), `token-router`, `scratchpad`, `agent-uplift`, `multi-cli`, `subagent-orchestration`, `long-run-harness`, `jarvis-evolve`.
- Autopilot hooks in `hooks/`: session boot, archetype router, correction detector, destructive guard, pre-compact checkpoint, verdict guard, token ledger, harness guard.
- 9 subagents in `agents/`.
- Multi-model gateway in `models/`: any provider in Claude Code's `/model`, Anthropic⇄OpenAI translation, `auto/*` fallback chains, quotas, loopback + token security. Docs in `docs/models.md`.
- Tests: installer merge/idempotency, destructive guard, gateway (37 node tests), hard-coded user-path guard. CI runs node tests.

### Fixed
- Removed author-specific paths, names and project references from commands, skills and templates.

## [0.1.0] — 2026-05-06

### Added
- Contrato operativo completo (`CLAUDE.md`) con motor de decisión de 8 arquetipos.
- Pack de 1400+ skills procedurales en `skills/`.
- Sistema de memoria wiki en `cerebro/` (índice, log, sesiones, fuentes).
- Runtime ejecutable `jarvis_runtime.py` con subcomandos: `doctor`, `providers`, `plan`, `session`, `memory`.
- Diagnóstico `jarvis_doctor.py` con modo `--repo-only` para validación de instalación.
- Comandos slash en `commands/` (memoria, consumo, ag-project, etc.).
- Sistema SaaS System + PRP + bucle agéntico para features complejas.
- Reglas por stack en `rules/` (common, web, mobile, backend).
- Templates MCP provider-agnostic en `mcp/`.
- Documentación reorganizada en `docs/` — root limpio con 5 archivos top-level.
- Playbook de adopción de patrones desde NousResearch/hermes-agent.
- Sanitización formal con `quarantine/` y política documentada.
